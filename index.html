1. The core idea: use the index to process every element

An array stores several values under one identifier. The index tells us which element we are working with. A loop lets us process every element efficiently.

Read five marks

FOR Index ← 1 TO 5 INPUT Marks[Index] NEXT Index

Output five marks

FOR Index ← 1 TO 5 OUTPUT Marks[Index] NEXT Index
Exam habit: if the array is `Marks[1:5]`, the loop normally runs from 1 to 5.

2. Total and average

Total ← 0 FOR Index ← 1 TO 5 Total ← Total + Marks[Index] NEXT Index Average ← Total / 5

Always initialise a running total to 0 before adding values.

3. Count values that meet a condition

PassCount ← 0 FOR Index ← 1 TO 5 IF Marks[Index] >= 50 THEN PassCount ← PassCount + 1 ENDIF NEXT Index

4. Find maximum and minimum

Maximum ← Marks[1] Minimum ← Marks[1] FOR Index ← 2 TO 5 IF Marks[Index] > Maximum THEN Maximum ← Marks[Index] ENDIF IF Marks[Index] < Minimum THEN Minimum ← Marks[Index] ENDIF NEXT Index
Common mistake: do not put the maximum test inside the `ELSE` of the minimum test. They are two independent checks.

5. Linear search using REPEAT ... UNTIL

INPUT SearchName Found ← FALSE Position ← 1 REPEAT IF StudentName[Position] = SearchName THEN Found ← TRUE ELSE Position ← Position + 1 ENDIF UNTIL Found = TRUE OR Position > 10

A linear search checks items one by one. It stops when the item is found or when the end of the array is reached.

6. 2D arrays use two indexes

FOR Row ← 1 TO 3 FOR Column ← 1 TO 4 OUTPUT Scores[Row, Column] NEXT Column NEXT Row

The outer loop changes the row. The inner loop moves across the columns.
