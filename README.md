# Paper 2 Mastery – Mission 9

## Mission 9: Array Processing & IGCSE Practice

For Secondary 3 Cambridge IGCSE Computer Science 0478.

### What this mission covers
- 1D array indexes
- Reading and writing array elements
- Totalling and average
- Counting values that meet a condition
- Maximum and minimum
- Linear search using `REPEAT ... UNTIL`
- 2D arrays and nested loops
- Debugging array pseudocode

### Mission structure
- I Do: teacher model and worked examples
- We Do: 10 guided questions with answer reveals
- You Do: 20 automatically checked questions
- Pass mark: 16/20 (80%)
- Bronze: 16–17
- Silver: 18–19
- Gold: 20/20
- Progress saved in the browser using localStorage
- Paste disabled in independent answer boxes

## Upload to GitHub
1. Create a repository named `paper2mission9`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**.
7. Save.

Your GitHub Pages address will normally be:
`https://<your-github-username>.github.io/paper2mission9/`
